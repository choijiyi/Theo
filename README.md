# 테오 (Theo)

2026 상명대 커뮤니케이션디자인과 졸업준비위원회 콜시트 · 캘린더 도구.

원래 claude.ai 아티펙트(실시간 공유 db)로 만들어졌던 것을 개인 정적 사이트로 옮긴 버전입니다.

## 구조

- `index.html` — 페이지 전체 (마크업 · CSS · JS 한 파일)
- `data/*.json` — 캘린더·과업·테이블·대여물품·배치도면·홍보물·이슈·학생 정보 등 모든 콘텐츠
- `images/` — 각 데이터에 첨부된 이미지 파일 (기존에는 db 문서 안에 base64로 압축해 넣어야 했지만, 이제는 일반 파일이라 압축 제약이 없습니다)

## 데이터 갱신 방법

이 사이트는 정적 사이트라 브라우저에서 직접 편집·저장이 안 됩니다. 회의록 작성, 과업 추가/완료, 일정 변경, 새 이슈·자료 등록 같은 내용 변경은 테오(Claude)와의 대화창에서 요청하면:

1. Claude가 `data/*.json`(필요하면 `images/`)을 수정
2. 이 레포에 커밋
3. 깃허브 페이지가 자동으로 재배포

식으로 반영됩니다.

## 회의 요약 (AI 요약) 관련

원래 있던 "테오에게 요약 요청" 버튼은 claude.ai 아티펙트 안에서만 동작하는 기능이라 이 정적 사이트에는 없습니다. 회의록 요약이 필요하면 테오(Claude)에게 채팅으로 회의록을 붙여넣고 요약을 요청하면 됩니다.

## 배포

깃허브 페이지(퍼블릭 리포 + `robots.txt`/`noindex` 메타태그로 검색엔진 노출만 차단)로 배포되어 있습니다. URL을 아는 사람만 접근 가능하며, 진짜 로그인 기반 비공개는 아닙니다.
